| Svelte and SvelteKit | [svelte.md](svelte.md) | `@inlaylab/opaline-svelte` |
| Angular | [angular.md](angular.md) | `@inlaylab/opaline-angular` |
| Web Components | [web-components.md](web-components.md) | `@inlaylab/opaline-element` |
